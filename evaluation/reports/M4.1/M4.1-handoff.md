1. 将当前实现提交，使 source tree clean；保留用户已有修改并单独处理其提交策略。
2. 在安全环境显式设置 `DEEPSEEK_API_KEY` 与 `DEEPSEEK_MODEL`，保持 strict 配置：无 retry、无 cache、无 fallback、无 partial success。
3. 执行：

   ```powershell
   venv\Scripts\python -m evaluation.stage_acceptance --stage M4.1 --mode all
   ```

4. 只有得到 `LIVE_BASELINE_SUCCESS`、逐案结果可比且无 evaluator error，才可进行 M4.1 正式验收结论。
5. M4.1 正式验收后，再按路线图判断 M4.2；不得用本次离线 Component/Integration 结果跳过 Live 门。
