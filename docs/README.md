# 项目文档索引

`docs/` 是项目的参考资料区，不是每次开发的默认上下文。开发时先看当前任务、相关代码和测试，再按需要打开对应文档；不要为了开始一个小切片而通读 M4.2～M9 全部内容。

`项目方向卡.md` 保存长期方向和稳定边界。`phase-cards/` 只保存当前开发切片的轻量执行卡，不是规格书。`architecture/架构.md` 保存架构背景和历史决策。`roadmap/` 保存阶段目标、阶段历史和未来目标，其中尚未开发的阶段只代表方向，不代表能力已经存在。`adr/` 保存重要技术决策，`contracts/` 保存历史领域契约，`technical-notes/` 保存技术解析，`project-log/` 保存阶段过程记录，`superpowers/plans/` 保存历史或局部执行计划。

开始一个新阶段时，只建立当前阶段的轻量阶段卡，不提前为所有未来阶段设计字段、阈值和实现计划。阶段完成后，用代码、测试、实际运行结果和人工可读验收记录更新相应的阶段记录。
