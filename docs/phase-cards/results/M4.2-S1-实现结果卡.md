# M4.2-S1 实现结果卡

> 性质：阶段卡的实现结果记录，不是规格书
>
> 当前状态：代码、离线和 Live 机器验收完成；人工复核未完成，阶段尚未正式关闭

本轮在已有单人商务差旅链路上收缩产品边界。当前产品只规划单人商务差旅的会前到达方案；普通旅游和多人商务差旅只做识别与明确拒答，不进入 Planner，不调用外部研究，也不生成旅游方案或多人行程。

单人商务差旅的默认假设策略保持不变。会议城市能够唯一映射到受控的 IANA 时区时，系统可以生成未确认的会议时区假设；没有人数且没有多人表达时，系统可以生成 1 人假设。显式提供的时区和人数仍然作为用户事实保留，不被假设覆盖。

本轮新增 `BusinessTripBoundaryResolver`。它先读取 Interpreter 的结构化结果和原始输入：商务会议语义优先于旅游词语；商务会议请求出现人数大于 1 或受控多人表达时，返回 `MULTI_TRAVELER_UNSUPPORTED`；没有会议语义但出现明确旅游语义或旅游地点、活动类字段时，返回 `TOURISM_UNSUPPORTED`。没有明确边界信号的历史泛化请求继续保留兼容路径，不在本轮删除旧旅游代码。

Router 统一把这两类边界转换为 `UNSUPPORTED`。拒答结果不携带能力、不生成澄清问题、`continue_to_planner=False`，状态保持 `collecting`。G0 安全阻断仍然优先于产品边界判断。Facade 和语义评测用例都把边界判断传入 Router，避免各层重复判断。

四类人工案例的业务目标已经冻结：BT-ACC-001 验证上海会议缺少时区和人数时的单人默认假设；BT-ACC-002 验证明确单人、明确时区不生成假设；BT-ACC-003 验证“我和两位同事”识别为 3 人后拒答；BT-ACC-004 验证普通旅游请求返回旅游不支持。四类案例都要求 Planner 调用为 0。

人工摘要会先显示运行来源、网络调用次数、Planner 调用次数和最终结论，再显示用户事实、系统假设、边界原因与关键字段。离线报告标记为固定响应、网络调用为 0；Live 报告标记为真实 DeepSeek 和实际网络调用次数。完整 Prompt、原始 LLM 响应和密钥不写入报告。

本轮不修改 `InterpretationResult` 结构，不让 LLM 负责边界决策，不建设多人行程模型，不接入真实政策、交通、酒店或地图供应商，不处理返程、景点、活动、预订、付款、取消或改签，也不删除历史旅游领域模型和兼容测试。

最终验证已经记录相关单元测试、四个离线人工案例、四个 Live 案例、Ruff、全量 pytest、`git diff --check` 和一次反向变异验证。全量 pytest 为 `765 passed, 9 deselected`；边界相关定向测试为 `56 passed`；相关修改文件 Ruff 通过，`git diff --check` 通过。全仓 Ruff 仍有 16 项既有格式或规则问题，集中在历史评分、阶段入口和旧测试文件，未扩大为本轮清理。测试通过、JSON 合法和网络调用成功只能证明机器或调用链路行为，不能替代四份 `human-review.md` 的人工判断。

最终四个离线案例的机器验证均为 PASS，网络调用均为 0；四个 Live 案例均来自真实 DeepSeek，各调用网络 1 次，Planner 均为 0。BT-ACC-001 和 BT-ACC-002 进入单人商务差旅的语义与初始路由；BT-ACC-003 识别为 3 人并返回 `MULTI_TRAVELER_UNSUPPORTED`；BT-ACC-004 返回 `TOURISM_UNSUPPORTED`。八份报告的阶段门状态均为 `HUMAN_REVIEW_PENDING`，因此这些结果还没有打开正式阶段门。

当前正式阻塞项是四份人工验收记录尚未完成。若任一多人或旅游案例进入 Planner、携带能力或生成澄清，或单人商务主链路被破坏，则代码验收也阻塞；在人工复核完成前不能进入 M4.2-S2。

## 历史证据

Interpreter 修复前的真实 DeepSeek 记录曾出现会议字段提取成功但通用 `destination`、`date_range` 或 `travelers` 缺失。这些记录用于定位 Interpreter 合同问题，不代表当前边界策略的通过证据。

默认假设策略的历史 Live 记录已经证明上海可生成 `Asia/Shanghai` 和 1 人未确认假设，明确时区和人数不会被覆盖。旧 BT-ACC-003 的输入与期望曾不一致：输入没有出发地，却要求杭州；输入明确包含“两位同事”，却要求人数阻塞。本轮已按新的多人拒答边界重写案例，旧报告不能继续作为当前证据。
