- Extended `WorkflowErrorPayload`, `WorkflowErrorSummary`, and Live attempt artifacts with safe trace/stage/category/code/retryability and bounded provider metadata. Unknown provider exception text is not copied into artifacts.
- No retry, cache, fallback, synthetic success, partial success, or M4 business semantic changes were introduced.
- Verification: targeted regression `35 passed`; full pytest `685 passed, 9 deselected`; Ruff targeted `All checks passed`; M4.1 offline acceptance all seven checks `PASS`.
- Full mypy remains blocked by 83 pre-existing errors in six existing `src` modules; none reference the changed files. This remains a known repository type-debt item, not a new M4.1 failure.

- The first real Live run reached DeepSeek and exposed a genuine semantic failure at `BT-M41-007`: `constraint_service` rejected a policy ceiling misclassified as a numeric `budget`.
